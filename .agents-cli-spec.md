# Agent Spec: Personalized AI/ML News Summary Generator

## Overview
A fully personalized AI/ML intelligence briefing system that ingests, curates, verifies, and delivers daily news briefs tailored to the user's specific research and engineering interests. It orchestrates multiple specialized agents using sequential, parallel, and loop topologies:
- **Ingestion & Retrieval Agent (Parallel/Retrieval)**: Fetches recent AI/ML papers, blogs, and news sources, leveraging retrieval tools/RAG.
- **Curator & Personalizer Agent (Loop/Memory)**: Matches articles against user preferences stored in long-term memory (`cross-session-memory`).
- **Verifier & Critic Agent (Loop / LLM-as-a-Judge)**: Fact-checks and evaluates technical claims, scoring summaries for accuracy and relevance.
- **Delivery & A2A Coordinator (Sequential/A2A)**: Coordinates brief formatting and delivers daily briefs via structured A2A messaging.

## Example Use Cases
- Input: "Generate my daily AI/ML briefing focused on LLM agents and multi-modal models."
- Output: A comprehensive, verified, highly personalized daily intelligence brief with citations and source links.

## Tools Required
- **Retrieval / RAG Tools**: Search over recent ML papers and news articles.
- **Cross-Session Memory**: Store and retrieve user preferences, topics of interest, and reading history.
- **A2A Messaging**: Structured communication between sub-agents (Ingestion, Curator, Verifier, Delivery).

## Constraints & Safety Rules
- Ground all summaries in retrieved sources with verifiable citations.
- Avoid hallucinating model benchmarks or paper titles.
- Respect user topic filters and length constraints stored in long-term memory.

## Success Criteria
- Evaluated via `agents-cli eval` with LLM-as-a-judge grading precision, relevance, and citation grounding.
